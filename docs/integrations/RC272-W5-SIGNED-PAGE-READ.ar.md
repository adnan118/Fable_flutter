# RC272 — قائمة قراءة مرقّمة آمنة لعقد Fable

**الحالة: تنفيذ مصدر فقط.** تمكين `GET *.list.paginated` في وضع `page`، ولا يتم إظهار البحث الحر أو الفلاتر أو الفرز قبل بناء مدخلاتها وربطها بالعقد فعليًا.

## مصدر الحقيقة

عقد Backend المصدّر من `Fable-Backend-RC66/lib/client-contract-export.mjs` يعلن `list-result` مع `meta.modes=['page','search']`، و`OpenAPI meta.oneOf` بصيغتي `page` و`search`. يستخدم المولّد فقط `page` و`limit` و`mode` بعد مطابقة أسماء المعاملات وتوقيع العملية وصلاحيات Bearer وتنسيق JSON وحقول العناصر ومعلومات الترقيم.

يُرسل Repository الطلب `page=رقم_صحيح` و`limit=20` و`mode=page` فقط. ولا يضيف `q` أو `sort` أو فلاتر بشكل تخميني، حتى لو كانت هذه المعاملات معرفة في العقد على أنها اختيارية.

## ما تمّ تنفيذه

- `Domain`: عناصر typed غير قابلة للتعديل وقائمة تشمل `page` و`limit` و`total` و`totalPages`.
- `Data`: فحص `items` و`meta` وتحقق رقم الصفحة والعدد الإجمالي والحدّ `20`، مع رفض اختلاف رقم الصفحة المطلوب عن الصفحة التي أعادها Backend.
- `UseCase/Controller`: التحقق من مجال رقم الصفحة، الحالات `Loading/Ready/Failed`، وإبطال نتائج الطلبات المتأخرة عند تغيير الهوية.
- `Flutter UI`: زر السابق/التالي بحسب `totalPages`، وحالة القائمة الفارغة أو فشل الاستعلام، مع إعادة رقم الصفحة إلى 1 بعد تغيير هوية المستخدم/Repository.
- إصلاح خطأ سابق في اختبارات Widget المولّدة (قوس ناقص في `tester.tap`).

**حدود الأمان:** يمنع المولّد العام إجراء Paging لكيان مُدار أو مملوك `managed-entity/owner` دون سياق Tenant موثّق. والعمليات التي تتطلب Query إلزاميًا أو ترويسات إضافية تظل خارج المسار الآلي، وتتطلب تكاملًا مخصصًا.

## ما لم يُثبت بعد

اختبارات المصدر المعزولة تغطي RC267 وRC270 وRC271 وRC272؛ لا تُعدّ هذه التجارب تشغيل `flutter test` أو Android/iOS أو Backend+MySQL E2E. ما زالت W5 وW6–W8 مفتوحة، مع **Production NO_GO**.
