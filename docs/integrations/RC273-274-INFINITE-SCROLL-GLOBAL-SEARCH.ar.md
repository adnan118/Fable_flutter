# RC273 + RC274 — Infinite Scroll ونتائج البحث المُرقّمة

**حالة التنفيذ:** مصدر Backend RC274 مدمج؛ مصدر Flutter RC273 في هذا التغيير. لم تُجرَ بعد تجربة تشغيلية على Backend+MySQL أو Android/iOS.

## هل يبحث Search في كامل البيانات؟

نعم؛ يرسل Backend استعلام `Prisma` إلى قاعدة البيانات مع شروط البحث على الحقول المسموحة ومعايير الفلترة وملكية السجل/الحساب، ثم يجلب **صفحة من كامل النتائج المطابقة والمسموح بها**. لا يجري البحث في العناصر التي سبق تحميلها على الهاتف فقط.

قبل RC274 كان وضع `search` يجلب أول 50 سجلًا دون `skip` أو `total`. أصبحت الـ50 **حدًا أقصى لكل صفحة**، وليس حدًا للبحث كله. مثال مفهوم من ميزة افتراضية تحتوي endpoint موثقًا:

```http
GET /catalog?q=hotel&mode=search&page=3&limit=20
```

صيغة الاستجابة الإيضاحية:

```json
{
  "success": true,
  "data": {
    "items": ["...up to 20 typed records..."],
    "meta": {
      "mode": "search",
      "page": 3,
      "limit": 20,
      "total": 137,
      "totalPages": 7,
      "count": 20
    }
  }
}
```

هذا مثال توضـيحي وليس نتيجة اتصال حي. `total` لجميع النتائج المسموحة المطابقة عبر قاعدة البيانات؛ `count` عدد العناصر المعادة **في هذه الصفحة**. `page` من 1 إلى 100000، و`limit` يصل إلى 50 فقط في `search`.

## Flutter — تمرير لا نهائي بدلاً من «التالي / السابق»

- مولّد الواجهات ينتج `ScrollController` و`ListView.builder` ويطلب الصفحة التالية عند الاقتراب من نهاية القائمة؛ ليس هناك أزرار تنقل يدوي بين الصفحات.
- Controller يحتفظ بالعناصر التي وصلت، والصفحة التالية، والعدد الإجمالي وحالة التحميل والخطأ. يمنع الطلبات المتزامنة، ويتجاهل نتائج الطلبات المتأخرة بعد تغيير الحساب أو نص البحث.
- يظهر حقل بحث عند استيراد عقد **RC274 المُرقّم والموقّع** فقط؛ تغيير العبارة يعيد الصفحة إلى 1، ويسمح بالاستمرار في تحميل بقية نتائج البحث تلقائيًا.
- إذا فشل تحميل صفحة تظهر إعادة محاولة لهذه الصفحة، وتُعرض العناصر المحملة سابقًا دون حذفها. يتم استخدام `limit=20` في التطبيق، مع بقاء الحد الأقصى في Backend عند 50.
- يستخدم التنفيذ أدوات Flutter القياسية، دون الاعتماد على مكتبة خارجية غير مُثبتة أو إضافة حزمة غير مطلوبة.

## توافق العقود

- العقود القديمة التي تصف بحثًا غير مُرقّم تستمر في دعم **Infinite Scroll للتصفح العادي فقط**؛ لا نعرض عليها بحثًا يوهم بتحميل جميع النتائج.
- العقود الجديدة تتضمن `search.meta: page,limit,total,totalPages,count` ومطابقة OpenAPI؛ يُفعّل البحث الشامل عند استيرادها وتوليد المشروع منها فقط.
- هذا التغيير في **المولّد** وليس نشرًا تلقائيًا إلى كل تطبيق أو Backend منشور قديم. يجب إعادة توليد/تحديث المشروع من العقد الجديد ونشر Backend قبل اعتماد البحث المُرقّم.

## الاعتمادية والاختبارات

- Backend: مصدر عدّ `count` وجلب `findMany(skip/take)` يعمل وفق نفس شروط `where` ويضيف ترتيبًا حاسمًا بالـID في البيانات المستقرة.
- المصدر وحده لا يمنع تحرّك العناصر بين الصفحات إذا تغيّرت البيانات أثناء القراءة؛ لثبات كامل مع تغييرات متزامنة قد نحتاج لاحقًا Cursor Pagination.
- الحالات المصدرية المضافة لـ RC273 وRC274 مع اختبارات رجوع RC267–272 ليست بديلًا عن `flutter test` أو اختبارات فعلية لـPrisma/MySQL وTenant أو الأجهزة.
- تظل مهام W5/W6/W7/W8 المتبقية وقرار الإنتاج **NO_GO** إلى أن تتوفر أدلة حقيقية.
